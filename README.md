# 注射美容 30 讲，把“打一针”还原成一次医疗决策

> 当前状态为 30 篇均已完成**可发布正文**，体例同 acid-peel-30，包括视角引导语、正文、证据边界与延伸阅读。配图已完成，共有 60 张文章配图和 6 张系列海报，文章配图已插入正文。配套静态网站见 [website/index.html](website/index.html)。

## 系列定位

这是一套以**普通消费者为主要读者**的注射美容科普系列。30 篇中有 24 篇消费者篇（80%）和 6 篇专业篇（20%）。与本库其他系列（激光、刷酸）以专业读者为主不同，本系列的默认读者是“正在被种草、还没走进机构”的人。

**总命题** 注射美容是一次医疗行为，不是一次消费。你买到的不是一支针剂，而是“合法的药械 + 有资质的人 + 有急救能力的场所 + 出问题时的责任闭环”这一整套系统。缺任何一环，价格再低都不便宜。

## 与消费者的三个约定

1. **不替你选项目。** 这套内容帮你识别风险、准备面诊、看懂知情同意，但不会告诉你"该打什么"。
2. **不提供可复制参数。** 不写剂量、单位数、注射层次和操作手法；这些属于面诊室，不属于公众号。
3. **永远保留"不打"这个选项。** 所有注射美容都是择期项目，可以等、可以问第二个医生、可以不做。

## 静态网站

网站为零依赖静态页面，可直接打开 `website/index.html`，也可在本目录运行以下命令。

```powershell
py -3 -m http.server 8000 --directory website
```

正文或配图更新后，使用以下命令重新生成并校验。

```powershell
py -3 scripts\build_website.py
py -3 scripts\validate_website.py
```
